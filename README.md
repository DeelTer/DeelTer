# Roman / DeelTer

Java backend developer. I build payment integrations, API clients and modular platforms
for gaming communities — from SDK design to production deploys.

[Telegram](https://t.me/deelter) · [Portfolio](https://deelter.ru)

---

## What I work on

- **Payment integrations** — YooKassa, Cryptomus: bills, webhooks, refunds, idempotency
- **API clients** — type-safe sync/async wrappers, WebSocket events, rate-limit handling
- **Modular backend platforms** — plugin architecture with isolated optional dependencies,
  per-module databases and schema migrations
- **Discord & Minecraft ecosystems** — bots, economy, inventories, shops, giveaways

### Selected work

**Bunny** — modular Discord platform, 25+ independently deployable modules
(economy, items, shops, donations, giveaways, tickets, forms, verification).

- Java 25, JDA 6, Components V2 UI
- Ebean ORM over HikariCP: PostgreSQL, MySQL and SQLite from one config switch
- Caffeine caching with write-behind persistence
- Payment flow with discounts, promo codes and free-purchase handling
- Module system with runtime-optional dependencies that never break class loading
